## 一、架构设计

### 核心原则：继承 v5，只替换选择和种群管理层

```

  ├─ 求值/缓存   ← 全部复用 →       复用

  ├─ 选择: 锦标赛/lexicase   →    覆写: 签名等权轮转 (2026-07-21)

  ├─                           →    新增: 周期性灭绝事件
  └─                           →    新增: 签名索引 (跨方向交叉)
```

## 二、关键发现

### 发现 1：triplet loss >> MSE

| 损失函数 | 冠军 SR | 说明 |
|:--------|:------|:-----|
| MSE (自编码器) | 0.703 | φ 空间坍缩, 单一方向 |
| **triplet (对比学习)** | **1.174** | 不同 fitness 层次分离, 突破性提升 |

**根因**: MSE 重建损失让相似输出但不同质量的表达式挤在同一个 φ 区域。triplet 损失主动推开不同 fitness 层次的 φ → 更多生态位。

### 发现 2：AURORA 成功突破 GP 盲区

**问题表达式**: `ts_predict(ts_kurt(HIGH, 21), 10)`
- 中间态 `ts_predict(ts_kurt(...))` → SR=0.089 → 标准 GP 直接淘汰
- 冠军 `neg(ts_predict(ts_kurt(...)))` → SR=1.174 → 标准 GP 永远无法从中间态到达

**AURORA 路径**:
1. 种子 `-ts_kurt(HIGH, 21)` → fit=0.557 → Archive 保留 (中间态存活!)
2. `ts_predict()` 变异包装 → `ts_predict(-ts_kurt(HIGH, 21), 10)` → fit=1.174

**独立验证**: kb03 07-d 手动测试 `neg(ts_predict(ts_kurt(HIGH,21),10))` → SR=1.174，与 v6 发现的 `ts_predict(-ts_kurt(HIGH,21),10)` 语义等价、SR一致。

### 发现 3：v6 冠军是 v5 冠军的 1.64 倍

| 引擎 | 冠军表达式 | Full SR |
|:-----|:---------|:------|
| v5 GPEngine (kb04 07-a) | `19 / ts_ar_resid(HIGH, 10)` | 0.715 |
| **v6 AURORA (kb05 R3)** | **`ts_predict(-ts_kurt(HIGH,21),10)`** | **1.174** |

v6 发现了 v5 根本到不了的高度。

### 发现 4：sig_quota 签名保护恢复多样性

| 配置 | Top-15 结构数 |
|:-----|:-----------|
| 无签名保护 (R1/R2) | 1 种 (全部相同) |
| **sig_quota=5 (R3)** | **5 种** |
| 多 seed 合并 (42+123) | **8 种 (接近 v5 的 ~10 种)** |

**实现**: 在 DNS 替换逻辑中加入三条签名规则：
1. 新签名进入 → 优先替换近邻中签名过量的个体
2. 签名已过量 (≥sig_quota) → 需 5%+ 提升才替换
3. 禁止删除某签名的最后一个代表

### 发现 5：签名计算缺失 bug

第一版 `_dns_replace` 加签名保护后毫无效果——所有个体的 `signature` 字段都是空字符串 `''`。

**根因**: AURORAEngine.run() 没有调用 v5 的 `_build_snapshot()` 来填充签名。修复：在 `_encode_individual()` 中调用 `self._expr_signature()`。

### 发现 6：签名引导完整方案 ✅ 2026-07-21

**问题**: 均匀随机采样 → 常见签名垄断繁殖 → 单轮仅 5 种结构；编码器冷启动期 φ 未成熟 → 误杀结构不同的个体。

**方案**（5 项改动，净增 ~60 行）:

| 改动 | 位置 | 说明 |
|:-----|:-----|:-----|
| `build_sig_index()` | `AuroraArchive` | 签名 → 个体列表索引 |
| `_select_parent` softmax(T=0.3) | `AURORAEngine` | 签名按 max_fitness 加权 |
| 交叉 `exclude_sig` | `_generate_children` | 跨方向结构重组 |
| 混合距离 (α×φ + (1-α)×sig) | `_dns_replace` | 冷启动签名兜底 |
| `_encoder_maturity()` | `AURORAEngine` | 训练次数 → α 过渡 |

**效果**（6 轮 seed=42 验证）:
- 冠军 fit 范围: 0.674 ~ 1.071（GP 固有波动）
- 结构家族: 5~10 种/轮，累计发现 5+ 个独立家族（ts_kurt/ts_skew/zscore/argmin/kama）
- 灭绝后签名: 72~99 个方向存活

## 三、v5 vs v6 本质对比

| 维度 | v5 GPEngine | v6 AURORAEngine |
|:-----|:----------|:--------------|
| **选择** | lexicase 方向轮转 | softmax(fitness/T=0.3) + 跨方向交叉 |
| **种群** | fitness 末位淘汰 | DNS Archive + sig_quota + 混合距离 |
| **跨代记忆** | 无 | Archive 长期保留 |
| **中间态保护** | 无 (低分直接淘汰) | 种子+Archive + 冷启动签名兜底 |
| **进化跳跃** | 岛屿迁移 | 灭绝事件 |
| **搜索深度** | 受限于贪心选择 | **可越过适应度山谷** |
| **横向覆盖** | ~10 种/轮 (但 CLOSE 坍缩到 1) | 5~10 种/轮, 多轮累计 5+ 家族 |
| **冠军质量 (HIGH)** | SR=0.715 | **SR=1.038~1.071 (多轮最佳)** |
| **冠军质量 (CLOSE)** | SR=0.913 (但 10/10 同结构) | SR=0.840 (8 个家族) |
| **确定性** | ✅ 同 seed 完全复现 | ⚠️ encoder 训练未种子化 |
| **评估量** | 20,000 | 15,500 (250×60+500) |
| **双重求值** | 无 | ✅ 已修复 (2026-07-21) |

### v6 不需要岛屿

Archive + sig_quota 已实现岛屿隔离效果（各签名独立生态位），灭绝事件取代了迁移功能（制造进化瓶颈打破局部最优）。

### 论文原味 vs 当前实现

| 环节 | 论文方法 | 当前实现 | 差距 |
|:-----|:-------|:-------|:-----|
| 选择 | 均匀随机 (φ 分层) | 签名等权轮转 (2026-07-21) | ✅ 已用签名替代 φ 分层 |
| φ 质量 | 1000步轨迹 → 清晰分离 | 8维统计 → 冠军签名垄断 φ | **核心瓶颈** |
| 替代方案 | — | 选择器加方向轮转 + 跨方向交叉 | 实用折中 |

## 五、优化清单 (2026-07-21 更新)

### ✅ 已完成

1. **方向感知选择 — softmax 签名加权**: `_select_parent` 改为 softmax(max_fitness(sig)/T=0.3)，好方向多繁殖但保留所有方向参与权。交叉 `exclude_sig` 强制跨方向重组。
2. **DNS 混合距离冷启动保护**: `_dns_replace` 混合 φ 距离 + 签名距离，冷启动 α=0.3→0.5→0.7→0.85→1.0 渐进过渡。防编码器未成熟时误杀。
3. **双重求值消除**: `_evaluate_individual` 缓存 `_factor_values`，编码阶段直接复用，省 ~50% 评估耗时。
4. **缓存命中种子因子值补全**: 缓存命中时仍调 evaluator 拿 `_factor_values`（仅 1% 开销），防种子被 archive 误拒。
5. **v5 残留初始化修复**: 恢复 `_use_lexicase` / `_num_islands` 初始化，修复 fallback 场景的 AttributeError。

### 🔲 待实施

6. **φ 编码器增强**: 8→16 维，增加多窗口偏度/峰度、5阶自相关、rank IC 均值/IR、截面 spread。需先完成具体维度设计。
7. **评估量平衡**: children_per_gen=250→400（当前 kb05 用 250，仍低于 v5 的 500）。
8. **灭绝保留签名覆盖**: 当前灭绝 `retention=0.25` 时随机保留，稀有签名可能丢失。改为每个签名至少保留 1 个代表。
9. **DNS 支配阈值修复**: `dists[ni] < np.median(dists)` → 绝对值阈值（archive 内 pairwise 距离的 25% 分位数）。
10. **encoder 训练随机种子固定**: `np.random.choice` → `self._rng.choice`，确保同 seed 完全可复现。
11. **sig_quota 调优**: 当前 kb05 用 8（偏宽松），R3 用 5 效果更好。需验证最优值。
